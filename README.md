# 🌊 AquaSense Pro — Live Water Level Monitoring

AquaSense Pro is an IoT-based water-level monitoring system using an **ESP32** and an **ultrasonic water-level sensor**.

The ESP32 measures the water depth and sends the sensor data to a web dashboard. The dashboard is designed to run on **GitHub Pages**.
